AKHUNZADA SALMAN SHOES WEBSITE

Files:
- index.html: website with HTML, CSS and JavaScript
- images/brand-logo.png: your supplied brand logo

IMPORTANT: Upload index.html and the entire images folder to the same GitHub repository root. Do not upload only index.html, because the logo is stored in images/brand-logo.png.

Product photos are sample online images. If an online product image fails, the page retries with a backup shoe image and then displays a built-in fallback graphic instead of a blank box. For the most reliable final store, replace sample images with your own product photos saved locally in the images folder.

GitHub Pages: Repository -> Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
